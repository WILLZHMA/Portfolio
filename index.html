工作工具 · 桌面應用

手機產品時間軸

開啟互動 Demo（前後代比較）→

把各品牌新機的上市時間、起售價與規格整理在同一列來進行前後代產品在同規格下價格漲幅的比較。

解決的問題

  • 競品資訊散落在網路與報表，每次比較都要重查
  • 跨世代漲跌價難以快速對照
  • 同事電腦環境受限，無法安裝複雜軟體

做法與亮點

  • 價格帶 × 時間的矩陣視圖，點機型看完整規格
  • 任兩支手機規格並排比較、前代起售價差
  • Python 打包成單一 .exe，雙擊即開，免安裝
  • 資料以標準化 JS 檔交換，非工程背景同事也能更新
PythonpywebviewHTML / CSS / JSPyInstaller 打包本機伺服器
選用 pywebview 而非 PyQt，是為了避開商業授權限制；工具完全本機執行，不需對外連線即可通過公司防火牆環境。
工作工具 · 資料整合

Market Intelligence

開啟互動 Demo →

整合三家第三方市場研究機構的 Excel 報表，統一欄位與口徑後，提供品牌、價格帶、季度的交叉篩選與趨勢圖，取代每季手動對表。

解決的問題

  • 三家資料來源格式、品牌命名、分類各不相同
  • 每季更新都要重做一次樞紐分析
  • 不同來源的數字差異難以並排檢視

做法與亮點

  • 將多來源 Excel 正規化為單一資料格式
  • 品牌份額、價格帶結構、季度趨勢一頁呈現
  • 可切換資料來源比較差異
  • 產業新聞跑馬燈：Excel 以網路連結接 RSS，經 Power Query 讀取成可重新整理的連線
  • 「更新新聞」按鈕放在 HTML 上，連接資料夾後即可每日一鍵更新新聞
  • 本機 127.0.0.1 執行，資料不離開電腦
PythonExcel 資料清理Power QueryRSSHTML / JS 視覺化資料正規化
工作工具 · 資料追蹤

Socket 追蹤表

開啟互動 Demo →

依品牌與產品線（Socket）追蹤各機型的銷售期間、晶片與供應商，以月份色塊呈現誰在哪段時間使用哪一顆晶片，並自動彙總年度與整體數量。

解決的問題

  • 產品線換代與晶片供應商切換散在多份表格，難以一眼看出時序
  • 每月更新時需要確認「這次到底改了什麼」
  • 資料需要在 Excel 與工具之間來回交換

做法與亮點

  • 寬表視圖依月份自動合併色塊，供應商以顏色區分
  • 長表、晶片比較、品牌與供應商佔比等多種檢視
  • 更新前先顯示新增／刪除／修改差異再確認
  • 支援 Excel 匯入匯出與從 Excel 貼上匯入
HTML / CSS / JSSheetJSExcelJS資料差異比對

產業結構觀察

開啟互動 Demo →GitHub

個人台股資料網站，以產業結構而非個股明牌為視角：類股指數、三大法人動向、ETF 成分股與月營收排行。標語是 Market Pulse, Not Advice。

功能

  • 台股大盤、類股指數與法人買賣超面板
  • ETF 持股爬蟲（逐一評估各投信網站可抓取性）
  • 月營收排行與自選股清單
  • Google OAuth 登入＋白名單控管

踩過的坑

  • FinMind API 欄位大小寫不一致導致的資料錯誤
  • 櫃買中心 SSL 憑證問題
  • 為部署 Cloud Run 將 session 移至 MySQL
  • 從 AWS EC2 遷移到自架 Ubuntu 迷你主機＋Cloudflare Tunnel

個人專案 · 靜態網站（示範資料）

GRGR 綠綠｜農業資訊平台

開啟入口頁 →

把農業新聞、上中下價與整體統計，依使用者角色分流：農友看今天賣哪裡、消費者看這週買什麼、政策者看市場總覽、研究者從問題開始分析。標語是「看見農業，洞察變化，創造成長」。

設計重點

  • 手機版 4 種角色入口，電腦版提供政策者「市場脈動儀表板」與研究者「研究工作台」
  • 入口頁以新聞跑馬燈與行情摘要呈現當日重點
  • 新聞與數字明確標示為示範資料，避免被誤認為真實行情

目前狀態與規劃

  • 純靜態前端，部署於 GitHub Pages
  • 內容由程式依日期產生示意資料
  • 正式版規劃串接政府與農業單位公開資訊，並標示來源與更新時間

Data & Business Analyst｜手機市場分析與決策支援

簡介

在半導體業手機 PM 部門擔任駐點 Data & Business Analyst。主要整合 BCI、GfK、IDC 等第三方手機市場資料，維護並建立成資料智庫，協助手機 PM 與主管分析區域市場、追蹤競品、討論策略時提供數據支持。另外也運用 Power BI 平台與前端介面，提供更快速、即時性的資料可視化。

工作經歷

Data & Business Analyst｜手機 PM 部門
半導體製造業（人力仲介派駐 · 500 人以上）2021/10 – 至今 · 新竹縣市
1. 市場資料清洗以及正規化

整合 BCI、GfK、IDC 等多來源市場研究資料，透過 Excel 與 Power Query / M 進行清洗、欄位合併與資料檢核，每次更新都會核對各來源的欄位是否一致；建立自動更新流程，降低團隊約 40% 重複人工處理時間。

2. 專題分析與策略支援

依 PM 與主管需求做專題分析，例如各價格帶的 SoC 廠商市佔、平台出貨與平台結構（Socket）分析、各 OEM 的 SoC 與平台滲透率、各價格帶的 OEM 出貨、BCI 月度 segment 分析、4G 價格帶下滑分析。

3. 跨部門協作與營運分析支援

配合產品管理、財務、庫存管理、業務管理及供應鏈管理等部門的資料需求，提供市場研究資料整理、分析與報表支援，協助不同業務單位取得所需的市場資訊。

4. Power BI 市場分析（DAX）

負責部門 Power BI 平台的架構與視覺化，使用 DAX 建立品牌全球市佔、OEM 與 SoC 的 TAM / SAM 占比趨勢、4G / 5G、價格帶、產品世代與區域 / 國家比較。

5. 手機市場追蹤與內部工具（自行開發：Python、PyWebView、HTML/CSS/JS）
  • 手機產品時間軸：依價格帶整理各品牌新機的上市時間與起始價格，針對中國各品牌機型做不同規格、前後代的價格對照，並連結手機規格詳細數據。
  • Market Intelligence：整合 BCI、GfK、IDC 的 Excel 資料、PM 預估數據以及 Sales 數據，進行庫存比對與未來預估；以 Power Query 串 RSS，每天更新市場新聞。
  • Socket 追蹤表、週報機型追蹤圖表：以 HTML 開發，用時間軸追蹤產品、銷售期間與晶片供應商，可做資料差異檢查與匯入匯出，讓使用者不用手動編修表格，也不用自己搜尋資料、製圖。
