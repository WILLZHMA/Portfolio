工作工具 · 桌面應用

手機產品時間軸

開啟互動 Demo（前後代比較）→

把各品牌新機的上市時間、起售價與規格整理在同一條時間軸上，以每 NT$1,000 為一個價格帶，一眼看出競品在哪個價位、什麼時間點出手。

解決的問題

  • 競品資訊散落在網路與報表，每次比較都要重查
  • 跨世代漲跌價難以快速對照
  • 同事電腦環境受限，無法安裝複雜軟體

做法與亮點

  • 價格帶 × 時間的矩陣視圖，點機型看完整規格
  • 任兩支手機規格並排比較、前代起售價差
  • Python 打包成單一 .exe，雙擊即開，免安裝
  • 資料以標準化 JS 檔交換，非工程背景同事也能更新
PythonpywebviewHTML / CSS / JSPyInstaller 打包本機伺服器
選用 pywebview 而非 PyQt，是為了避開商業授權限制；工具完全本機執行，不需對外連線即可通過公司防火牆環境。
工作工具 · 資料整合

Market Intelligence

開啟互動 Demo →

整合三家第三方市場研究機構的 Excel 報表，統一欄位與口徑後，提供品牌、價格帶、季度的交叉篩選與趨勢圖，取代每季手動對表。

解決的問題

  • 三家資料來源格式、品牌命名、分類各不相同
  • 每季更新都要重做一次樞紐分析
  • 不同來源的數字差異難以並排檢視

做法與亮點

  • 將多來源 Excel 正規化為單一資料格式
  • 品牌份額、價格帶結構、季度趨勢一頁呈現
  • 可切換資料來源比較差異
  • 產業新聞跑馬燈：Excel 以網路連結接 RSS，經 Power Query 讀取成可重新整理的連線
  • 「更新新聞」按鈕放在 HTML 上，連接資料夾後即可每日一鍵更新新聞
  • 本機 127.0.0.1 執行，資料不離開電腦
PythonExcel 資料清理Power QueryRSSHTML / JS 視覺化資料正規化
工作工具 · 資料追蹤

Socket 追蹤表

開啟互動 Demo →

依品牌與產品線（Socket）追蹤各機型的銷售期間、晶片與供應商，以月份色塊呈現誰在哪段時間使用哪一顆晶片，並自動彙總年度與整體數量。

解決的問題

  • 產品線換代與晶片供應商切換散在多份表格，難以一眼看出時序
  • 每月更新時需要確認「這次到底改了什麼」
  • 資料需要在 Excel 與工具之間來回交換

做法與亮點

  • 寬表視圖依月份自動合併色塊，供應商以顏色區分
  • 長表、晶片比較、品牌與供應商佔比等多種檢視
  • 更新前先顯示新增／刪除／修改差異再確認
  • 支援 Excel 匯入匯出與從 Excel 貼上匯入
HTML / CSS / JSSheetJSExcelJS資料差異比對
個人專案 · 全端網站

產業結構觀察

開啟互動 Demo →GitHub

個人台股資料網站，以產業結構而非個股明牌為視角：類股指數、三大法人動向、ETF 成分股與月營收排行。標語是 Market Pulse, Not Advice。

功能

  • 台股大盤、類股指數與法人買賣超面板
  • ETF 持股爬蟲（逐一評估各投信網站可抓取性）
  • 月營收排行與自選股清單
  • Google OAuth 登入＋白名單控管

踩過的坑

  • FinMind API 欄位大小寫不一致導致的資料錯誤
  • 櫃買中心 SSL 憑證問題
  • 為部署 Cloud Run 將 session 移至 MySQL
  • 從 AWS EC2 遷移到自架 Ubuntu 迷你主機＋Cloudflare Tunnel
